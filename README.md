# Prototype MCN – Groupe 4 (ESMT)

Site pédagogique **non officiel** : version améliorée du site du Musée des Civilisations noires (Dakar), réalisée dans le module Audit digital du Master 1 MTD de l'ESMT.

Chaque modification enregistrée sur la branche `main` est publiée automatiquement par Vercel.

## Où modifier quoi

| Je veux changer… | Fichier |
| --- | --- |
| Le texte de l'accueil | `index.html` |
| Horaires, tarifs, accès, FAQ | `visite.html` |
| La liste des expositions | `expositions.html` |
| Le contenu d'une fiche exposition | `assets/expos.js` |
| Visites de groupe, formulaire | `groupes.html` |
| L'agenda | `agenda.html` |
| À propos, contact, projet | `a-propos.html`, `contact.html`, `projet.html` |
| Menu et pied de page (toutes les pages) | `assets/layout.js` |
| Couleurs, polices, mise en page | `assets/style.css` |
| Numéro WhatsApp de test | `assets/app.js` (`WA_NUMBER`) |
| ID Google Analytics 4 | `assets/config.js` |

## Modifier depuis le navigateur

1. Ouvrir le fichier sur GitHub, cliquer sur l'icône crayon.
2. Faire la modification.
3. Cliquer sur **Commit changes**. Le site se met à jour en une minute environ.

## Règles du projet

- Garder le bandeau « site non officiel » sur chaque page.
- Ne jamais ajouter le logo officiel du musée. Les photos viennent de Wikimedia Commons (licence libre) : garder le nom de l’auteur et la licence, et compléter les crédits dans projet.html si une photo est ajoutée.
- Ne jamais mettre les vraies coordonnées du musée dans un formulaire ou un bouton de test.
